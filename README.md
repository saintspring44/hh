# Telegram File Assistant

Telegram-бот для управления файлами в собственной папке данных.

## Возможности

- Создание папок и файлов
- Запись и чтение текстовых файлов
- Список файлов и папок
- Загрузка документов в Telegram и скачивание файлов из бота
- Переименование и удаление файлов
- Доступ только для указанных Telegram ID

## Настройка

1. Создай бота через [@BotFather](https://t.me/BotFather) и скопируй токен.
2. Узнай свой Telegram ID у любого ID-бота или после запуска временно посмотри ID в сообщении `/id`.
3. Установи Python 3.10+.
4. Установи зависимости: `pip install -r requirements.txt`.
5. Создай файл `.env` на основе `.env.example` и заполни `BOT_TOKEN` и `ADMIN_USER_IDS`.
6. Запусти: `python bot.py`.

Переменные окружения:
- `BOT_TOKEN` — токен от BotFather.
- `ADMIN_USER_IDS` — список разрешённых Telegram ID через запятую.
- `DATA_DIR` — папка хранения (по умолчанию `data`).

**Важно:** не публикуй настоящий токен бота и не загружай файл `.env` в GitHub.
